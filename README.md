# Journal

A private, offline daily journal: one line a day, habit tracker, sleep/stat chart, search.

- Works fully offline once installed (Safari → Share → Add to Home Screen).
- Everything is stored encrypted (AES-256) on your device only. The page is not allowed to make network requests (`connect-src 'none'`).
- Backups are password-encrypted and compatible with the native iOS app.

Run the logic checks: `node core.test.mjs`
